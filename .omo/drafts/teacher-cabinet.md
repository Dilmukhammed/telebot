# Кабинет преподавателя — функционал

## Роль: Преподаватель
Взаимодействие через Telegram бота (Mini App для расширенного, команды для быстрого).

---

## 1. Расписание
- Вид: **день + неделя** (преподаватель переключается)
- Показывать **прошедшие и будущие** занятия
- Из карточки занятия — быстрый переход: посещаемость / оценки / материалы
- Индивидуальные занятия — **такой же вид** как групповые
- Команда бота: `/schedule` или кнопка «📅 Расписание»
- Карточка занятия: время, группа/ученик, предмет, формат (очно/онлайн), аудитория/ссылка, кол-во студентов

## 2. Группы и студенты
- Список своих групп
- Состав группы: студенты, контакты (Telegram @username)
- История посещений студента
- Команда: `/groups` → выбрать группу → список студентов

## 3. Посещаемость
- Быстрая отметка: **чеклист** — список студентов, напротив каждого ✓ был / ✗ не бит / ⏰ опоздал
- Сохранение: «Сохранить» внизу экрана
- Изменение: **в течение дня** можно изменить. Потом — только через админа
- История: **по студенту** — сколько занятий посетил, сколько пропустил
- Индивидуальные: чеклист из одного студента (тот же интерфейс)
- Команда: `/attendance` или кнопка из карточки занятия

## 4. Оценки
- Шкала: **баллы 0-100**
- Комментарий: **да** — что хорошо, что подтянуть
- Когда ставить: **только из карточки занятия** — привязано к дате и группе
- Интерфейс: список студентов → ввод балла → опциональный комментарий → сохранить
- История: **полная** — средний балл, динамика (график), все оценки по предмету
- Индивидуальные: оценка сразу выставляется (один студент)
- Команда: кнопка из карточки занятия

## 5. История студента
- Карточка студента: группы, оценки, посещаемость
- Прогресс за период (месяц/курс)
- Команда: `/student @username`

---

## Открытые вопросы
- [x] Нужны ли уведомления преподавателю? → **Да**: за час до занятия, новый студент в группе
- [x] Нужен ли учёт зарплаты преподавателя? → **Да**: ставка × количество проведённых занятий, админ видит
- [x] Какой интерфейс предпочтительнее? → **Mini App** (не кнопки в боте)
- [x] Нужна ли загрузка материалов к уроку? → **Да**: PDF/фото/ссылки, студенты видят

## Новые пункты

## 6. Зарплата преподавателя
- Формула: **фикс 3 000 000** + если учеников > 10 → **+250 000 за каждого** сверх 10
- Пример: 12 учеников → 3 000 000 + 2×250 000 = 3 500 000
- Количество учеников: **уникальные ученики, посетившие занятия в текущем месяце**
- Преподаватель видит: **текущий месяц + история** предыдущих месяцев
- Выплата: **админ отмечает «выплачено»** → баланс обнуляется
- Админ видит ведомость по всем преподавателям: кто, сколько, выплачено/нет

## 7. Уведомления преподавателю
- Напоминание за 1 час до занятия (группа, время, студенты)
- Оповещение: новый студент записался в группу
- Оповещение: студент отменил запись

## 8. Материалы к уроку
- Преподаватель прикрепляет файл/ссылку к конкретному занятию
- Студенты видят материалы в своём кабинете
- Форматы: PDF, фото, ссылка на Google Docs/YouTube
